# Surf Camp Hostel Management

## Description
A comprehensive management system for a surf camp hostel. This project aims to streamline operations related to bookings, classes, meal planning, bed assignments, and managing guest and staff information.

## Features
- **Booking Management:** Handle reservations, check-ins, and check-outs.
- **Class Scheduling:** Manage surf class schedules, instructor assignments, and student enrollments.
- **Meal Planning:** Organize meal preferences, dietary restrictions, and kitchen inventory.
- **Bed Management:** Track bed availability and assignments within dorms or private rooms.
- **People Management:** Maintain profiles for guests, staff, and instructors.
- **Billing and Payments:** Generate invoices and track payments.
- **Reporting:** Provide insights into occupancy rates, revenue, and other key metrics.

## Technologies Used
- **Backend:** Java (Spring Boot 3.2.5)
- **Frontend:** JavaScript (React)
- **Database:** PostgreSQL/MySQL (to be decided)

## Getting Started

### Prerequisites
- Java 17 or later
- Maven
- Node.js and npm

### Backend (Spring Boot)
1. Navigate to the `backend` directory:
   ```bash
   cd backend
   ```
2. Run the application:
   ```bash
   ./mvnw spring-boot:run
   ```
   The backend will typically start on port 8080.

### Frontend (React)
1. Navigate to the `frontend` directory:
   ```bash
   cd frontend
   ```
2. Install dependencies:
   ```bash
   npm install
   ```
3. Start the development server:
   ```bash
   npm start
   ```
   The frontend will typically open in your browser at http://localhost:3000.
